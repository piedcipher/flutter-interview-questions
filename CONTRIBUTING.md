# Contributing

Thanks for helping improve this collection of Flutter interview questions and answers.

## What to contribute

- Add clear, relevant Flutter and Dart interview questions.
- Keep answers technically accurate, concise, and useful for interview preparation.
- Include code examples when they make an answer easier to understand, and make sure examples are properly formatted.
- Correct outdated or inaccurate information and improve existing explanations.

## Submitting a change

1. Open an issue or pull request describing the question, correction, or improvement.
2. Keep changes focused and use clear headings and Markdown formatting.
3. For code examples, check that they are syntactically valid and identify any platform-specific behavior.
4. Review the rendered Markdown before submitting.

Please be respectful and constructive in discussions and reviews.
