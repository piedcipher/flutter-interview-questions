# Flutter interview questions

Use this skill when adding, revising, or reviewing interview questions and answers in this repository.

1. Read `README.md` and `CONTRIBUTING.md` first. Check for existing questions on the topic and update an existing answer rather than duplicate it when appropriate.
2. Write a clear question and a concise, technically accurate answer suitable for interview preparation. Explain important trade-offs and platform or version differences when relevant.
3. Verify version-sensitive or uncertain claims against official Flutter or Dart documentation. If a claim cannot be verified, say so rather than guessing; link to sources when useful.
4. Include a short, correctly formatted Dart example when it helps explain the answer. Ensure the example is syntactically valid and consistent with the explanation.
5. Follow the README's numbered headings and preserve sequential numbering when inserting or moving questions. Keep changes focused and retain unrelated content.
6. Review the final Markdown and report what changed, along with any verification limitations.
